# Trama — Versión 1.2

Fecha de respaldo: 3 de noviembre de 2026.

Estado guardado:
- Pizarrón y herramientas de participantes, selección grupal, miradas y trayectorias.
- Biblioteca local de canciones, onda de audio y espectro de frecuencias.
- Línea de tiempo con cortes editables y duración entre formaciones.
- Distribución compacta para ver juntos el pizarrón y la canción.
- Persistencia, historial, exportación y conexión existente con Supabase.

El ZIP conserva el proyecto completo, incluidos los cambios locales, pruebas, documentación y el historial Git disponible. Para recuperar esta versión, extraerlo en una carpeta nueva y servir la carpeta emiproyects/dist.

Los datos de coreografías y canciones guardados en el navegador o en Supabase son externos al proyecto y no están incluidos en este respaldo.
